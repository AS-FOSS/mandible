When run, this command will remove the shims for the specified package managers 
from the install directory, or all shims if no parameters are passed.

By default it will locate the install directory by running the equivalent of 
[36m`which corepack`[39m, but this can be tweaked by explicitly passing the install 
directory via the [36m`--install-directory`[39m flag.

Disable all shims, removing them if they're next to the [36m`coreshim`[39m binary
  [1m$ [22mcorepack disable

Disable all shims, removing them from the specified directory
  [1m$ [22mcorepack disable --install-directory /path/to/bin

Disable the Yarn shim only
  [1m$ [22mcorepack disable yarn
