Version 11.22.0
Usage: pnpm [command] [flags]
       pnpm [ -h | --help | -v | --version ]

Manage your dependencies:
      add                  Installs a package and any packages that it depends
                           on. By default, any new package is installed as a
                           prod dependency
      clean                Safely remove node_modules directories from all
                           workspace projects
      dedupe               Perform an install removing older dependencies in the
                           lockfile if a newer version can be used
      fetch                Fetch packages from a lockfile into virtual store,
                           package manifest is ignored
      import               Generates a pnpm-lock.yaml from an npm
                           package-lock.json (or npm-shrinkwrap.json) file
   i, install              Install all dependencies for a project
  it, install-test         Runs a pnpm install followed immediately by a pnpm
                           test
  ln, link                 Connect the local project to another one
      prune                Removes extraneous packages
  rb, rebuild              Rebuild a package
  rm, remove               Removes packages from node_modules and from the
                           project's package.json
      unlink               Unlinks a package. Like yarn unlink but pnpm
                           re-installs the dependency after removing the
                           external link
  up, update               Updates packages to their latest version based on the
                           specified range

Patch your dependencies:
      patch                Prepare a package for patching
      patch-commit         Generate a patch out of a directory
      patch-remove         Remove existing patch files

Review your dependencies:
      audit                Checks for known security issues with the installed
                           packages
      licenses             Check licenses in consumed packages
  ls, list                 Print all the versions of packages that are
                           installed, as well as their dependencies, in a
                           tree-structure
      outdated             Check for outdated packages
      why                  Shows all packages that depend on the specified
                           package

Run your scripts:
      approve-builds       Approve dependencies for running scripts during
                           installation
      create               Create a project from a "create-*" or "@foo/create-*"
                           starter kit
      dlx                  Fetches a package from the registry without
                           installing it as a dependency, hot loads it, and runs
                           whatever default command binary it exposes
      exec                 Executes a shell command in scope of a project
      ignored-builds       Print the list of packages with blocked build scripts
      run                  Runs a defined package script
      start                Runs an arbitrary command specified in the package's
                           "start" property of its "scripts" object
   t, test                 Runs a package's "test" script, if one was provided

Other:
      bin                  Prints the directory into which the executables of
                           dependencies are linked
   c, config               Manage the pnpm configuration files
      deploy               Deploy a package from a workspace
      init                 Create a package.json file
      pack                 Create a tarball from a package
      publish              Publishes a package to the registry
      root                 Prints the effective modules directory
      stage                Stage packages for publishing

Manage your engines:
      env                  Manage Node.js versions (deprecated, use runtime)
  rt, runtime              Manage runtimes
      self-update          Updates pnpm to the latest version

Inspect your store:
      cat-file             Prints the contents of a file based on the hash value
                           stored in the index file
      cat-index            Prints the index file of a specific package from the
                           store
      find-hash            Experimental! Lists the packages that include the
                           file with the specified hash

Manage your store:
      store add            Adds new packages to the pnpm store directly. Does
                           not modify any projects or files outside the store
      store path           Prints the path to the active store directory
      store prune          Removes unreferenced (extraneous, orphan) packages
                           from the store
      store status         Checks for modified packages in the store

Manage your cache:
      cache delete           Experimental! Deletes metadata cache for the
                             specified package(s). Supports patterns
      cache list             Experimental! Lists the available packages metadata
                             cache. Supports filtering by glob
      cache list-registries  Experimental! Lists all registries that have their
                             metadata cache locally
      cache view             Experimental! Views information from the specified
                             package's cache

Options:
  -r, --recursive          Run the command for each project in the workspace.
