OVERVIEW: Split input into multiple parts separated by regex '^(.|//)--- ' and extract the part specified by '^(.|//)--- <part>'

USAGE: split-file-18 [options] filename directory

OPTIONS:

Generic Options:

  --help             - Display available options (--help-hidden for more)
  --help-list        - Display list of available options (--help-list-hidden for more)
  --version          - Display the version of this program

split-file Options:

  --leading-lines    - Preserve line numbers
  --no-leading-lines - Don't preserve line numbers (default)
